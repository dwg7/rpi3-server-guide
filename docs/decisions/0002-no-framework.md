# 0002: フレームワーク・ビルドツールチェーンを使わない

- ステータス: 採用
- 日付: 2026-09-30

## 背景

mkdocs-material や Docusaurus は、見た目やナビゲーションの点で魅力がある。
一方、本ガイドは少数の受け手(協力者と共同検証者)向けの数セクションの文書である。

## 決定

素のHTMLとCSSだけで書く。ビルド工程、パッケージマネージャ、外部フレームワークは使わない。

## 理由

- 数セクションの文書に対して過剰装備になる。
- kaga0・zukaku・kikimimi で一貫してきた「静的ファイルだけで完結する」作法を踏襲する。
- ビルド環境に依存しないため、メール添付やローカルでの閲覧でもそのまま開ける。
- 保守で壊れる部分が少なく、将来の引き継ぎも容易になる。

## 結果

- スタイルは `index.html` 内の `<style>` に書く。
- 共通化が必要になるほど増えた場合のみ、この決定を見直す。
