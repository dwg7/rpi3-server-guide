# 0001: 単一の長いHTMLページにする

- ステータス: 採用
- 日付: 2026-09-30

## 背景

このガイドは、協力者が実際にコマンドを打ちながら参照する「作業台の上に置く文書」である。
後日、同じ内容をPDFに書き出して協力者にメール送付する予定もある。

## 決定

`index.html` 1枚にまとめ、セクション移動はアンカーリンクで行う。
マルチページのドキュメントサイトにはしない。スライド形式にもしない。

## 理由

- セクション数が多くなく、複数ページに分ける利点が小さい。
- 1ページなら、PDF書き出しが単純になる(印刷用CSSだけで済む)。
- 作業中に画面を行き来せず、ページ内検索(Ctrl+F)で完結できる。

## 結果

- ページが長くなるため、先頭に目次(アンカーナビゲーション)を置く。
- 内容が大幅に増えた場合は、この決定を見直す。
