# 0003: GitHub Pages は main ブランチのルートから公開する

- ステータス: 採用
- 日付: 2026-09-30

## 背景

公開元には、main の `/`(ルート)、main の `/docs`、専用の `gh-pages` ブランチの3案があった。

## 決定

main ブランチの `/`(ルート)から公開する。`.nojekyll` を置き、Jekyll の処理を無効にする。

## 理由

- `index.html` をルートに置く構成は、リポジトリ構成方針(CLAUDE.md §5)と一致する。
- ビルドがないため、`gh-pages` ブランチは不要である。
- `/docs` 公開にすると `index.html` と `assets/` の移動が必要になり、得るものが少ない。

## 結果

- `docs/decisions/*.md` もURLで到達可能になるが、公開ページからはリンクしない。
  ADRは公開して差し支えない内容に限る。
- 公開前レビューの完了までは、Pages を有効化しない。
